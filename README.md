# טורניר כדורעף

אפליקציית ווב לטורניר כדורעף בין חברים: קבוצות מתחלפות בכל משחק, לכל שחקן ניקוד אישי, ודירוג חי שכולם רואים בלי להתחבר. רק המארגן יכול להזין תוצאות.

- **פיזור מקסימלי:** לוח המשחקים נבנה מראש כך ששותפים ויריבים חוזרים כמה שפחות, בלי הרכבים כפולים, וכל קבוצה מאוזנת בנים ובנות.
- **ניקוד:** נקודה לכל שחקן בקבוצה מנצחת. בשוויון מכריע ההפרש המצטבר בין הנקודות שנכבשו לנקודות שהוכנסו.
- **חי ובטוח:** הצופים רואים עדכונים כל כמה שניות. כתיבה אפשרית רק עם סיסמת מארגן שנבדקת בשרת.

## מבנה הפרויקט

```
public/                       האתר עצמו (קבצים סטטיים, בלי build)
  index.html                  המעטפת, טוענת את הקבצים לפי הסדר
  base.css  court.css         עיצוב כללי / כרטיס המגרש
  scheduler.js                האלגוריתם: בניית לוח משחקים + נתוני בדיקת פיזור
  backend.js                  חיבור ל-Supabase: קריאה, כניסת מארגן, שמירה
  stats.js                    ניקוד ודירוג, דף שחקן
  games.js                    רשימת משחקים וכרטיס המגרש (3 קדימה + 2 אחורה)
  admin.js                    לשונית ניהול ומסך הגדרה
  app.js                      הליבה: מצב, רינדור, אירועים (נטען אחרון)
supabase/
  schema.sql                  הטבלאות והרשאות הקריאה
  functions/tournament-save/  פונקציית השמירה ובדיקת הסיסמה
tests/                        בדיקות אוטומטיות
vercel.json                   פריסה ב-Vercel מתוך public/
```

סדר טעינת הסקריפטים חשוב: `scheduler → backend → stats → games → admin → app`.

## הרצה מקומית ובדיקות

```bash
npm install
npm test          # בדיקות האלגוריתם + בדיקת זרימה מלאה מול שרת מדומה
npm run serve     # מגיש את public/ מקומית
```

בדיקת האלגוריתם מוודאת, בין היתר: הרכב מגדרי נכון בכל קבוצה, רוטציית ספסל הוגנת, משחקים עם תוצאה לא משתנים, ובמצב של 4 בנים ו-6 בנות: אין הרכבים כפולים וחפיפה מינימלית בין משחקים רצופים.

## הקמה מאפס

1. **Supabase:** צרו פרויקט, והריצו את `supabase/schema.sql` ב-SQL Editor.
2. **סיסמת מארגן:** בחרו סיסמה ו-salt אקראי, חשבו גיבוב ושמרו אותו בטבלה (הסיסמה עצמה לא נשמרת):
   ```bash
   printf '%s' "SALTסיסמה-שלכם" | sha256sum
   ```
   ```sql
   insert into public.organizer_secret (id, salt, hash) values (1, 'SALT', 'ההאש-שחושב');
   ```
   הסיסמה מוקלדת באותיות קטנות (השרת והדף ממירים לאותיות קטנות).
3. **הפונקציה:** פרסו את `supabase/functions/tournament-save` (עם `verify_jwt` כבוי, כי הפונקציה בודקת סיסמה בעצמה).
4. **חיבור הממשק:** ב-`public/backend.js` עדכנו את `CFG` (כתובת הפרויקט, המפתח הציבורי `anon`, וכתובת הפונקציה).
5. **Vercel:** ייבאו את הריפו. ההגדרות נמצאות ב-`vercel.json` (תיקיית פלט `public`, בלי build). אם הפרויקט מוגן בהתחברות, כבו את Deployment Protection כדי שהחברים יוכלו להיכנס.
6. פתחו את האתר, לחצו **כניסת מארגן** בתחתית הדף, ויצרו את הטורניר.

## אבטחה

- המפתח `anon` ב-`backend.js` ציבורי מטבעו. את ההגנה נותנים כללי ההרשאה במסד: כולם קוראים רק את טבלת הטורניר, וטבלת הסיסמה סגורה לגמרי.
- אל תוסיפו לריפו את הסיסמה, את ה-salt ואת ה-hash.
- כל טקסט שמוזן (שמות, כותרת) מוצג כטקסט ולא כ-HTML.
